Available widget slots

These are the named injection points modules may target. Each is a bounded container with overflow: hidden.

  1. global.statusbar — bottom of every Client/Node window
  2. node.dashboard.widget — Node admin dashboard widgets
  3. space.header — top of Space view (Space-level chrome)
  4. room.toolbar — Room-level toolbar
  5. room.sidebar.top — top of right column
  6. room.sidebar.bottom — bottom of right column
  7. room.message.decorator — under each message body

Install Polls?

This is a user-mode module published by com.example. It runs in your client only — other people in your Spaces will not see it unless they install it themselves.

  1. Render in room.toolbar Inject UI controls into the per-room toolbar.

  2. Read messages in current Room Read message text and metadata for rooms you are viewing.

  3. Send room.message events on your behalf This module can post messages signed with your identity. You are responsible for what it posts.

  4. Persist module data locally Stores poll results in ./modules/com.example.polls/.

User-mode modules are not vetted by your Node operator. Install only modules from sources you trust. You can disable or uninstall any module at any time.
