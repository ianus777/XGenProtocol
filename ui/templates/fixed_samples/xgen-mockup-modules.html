Install Polls?

This is a user-mode module published by com.example. It runs in your client only — other people in your Spaces will not see it unless they install it themselves.

Render in room.toolbarInject UI controls into the per-room toolbar.
Read messages in current RoomRead message text and metadata for rooms you are viewing.
Send room.message events on your behalfThis module can post messages signed with your identity. You are responsible for what it posts.
Persist module data locallyStores poll results in ./modules/com.example.polls/.
User-mode modules are not vetted by your Node operator. Install only modules from sources you trust. You can disable or uninstall any module at any time from this screen.
