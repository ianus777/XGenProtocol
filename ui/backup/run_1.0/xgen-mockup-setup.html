Welcome to XGen

Three steps to create your local identity. Nothing is sent over the network.

  1. Display name
  2. Passphrase
  3. Generate keypair

Choose a display name

This is the name other people will see. You can change it any time.

Protect your identity

Your private key is encrypted with this passphrase and stored locally. If you forget it, your identity cannot be recovered — XGen has no server-side reset.

Local only — never transmitted. Argon2id derives a key. ChaCha20-Poly1305 encrypts xgen-client_keypair.enc.

Generate your keypair

Pressing Create identity generates an Ed25519 keypair on this machine. No server is contacted.

What happens next. XGen will silently scan ws://127.0.0.1:8080/xgen for a local Node. If nothing answers within 2 seconds, the client reaches READY (unconnected) — no error.
